# Desarrollo web · EstudIA

Repositorio del curso. Aquí encuentras el código de cada encuentro y el espacio de conversación del grupo.

**Qué vamos a construir:** un sitio web propio con HTML, CSS y JavaScript, versionado con Git y publicado en GitHub Pages. Cada persona (o equipo) trabaja en **su propio proyecto**. Los ejemplos de los encuentros sirven para practicar una técnica; no son un tema obligatorio.

## Cómo está organizado

```
encuentros/                  Código de cada encuentro (demo y práctica)
  01-tareas-de-una-pagina/
  02-una-pagina-en-dos-anchos/
  03-datos-que-se-vuelven-pagina/
```

Las soluciones de referencia se publican **después** de cada encuentro.

## Cómo usarlo

**Sin instalar nada:** las páginas de cada encuentro se pueden abrir en el navegador desde el enlace de GitHub Pages del curso: [páginas del encuentro 1](https://maikoldiaz.github.io/estudia-frontend-web/encuentros/01-tareas-de-una-pagina/).

**En tu computador:** botón verde **Code → Download ZIP**, descomprime y abre cualquier `.html` con doble clic. Más adelante, cuando trabajemos con Git:

```bash
git clone <URL de este repositorio>
cd estudia-frontend-web
git pull      # al inicio de cada encuentro, para traer lo nuevo
```

## Conversación del grupo (Discussions)

Usa la pestaña **Discussions** de este repositorio:

| Categoría | Para qué |
|---|---|
| ❓ Dudas | Pregunta diciendo **qué intentaste, qué esperabas y qué pasó** (una captura o el mensaje de la consola ayudan mucho). |
| 🛠️ Muestra tu avance | Comparte el enlace a tu página o a tu repo y pide una revisión concreta. |
| 📚 Recursos | Documentación, artículos o herramientas que te sirvieron, con una línea de por qué. |
| 💬 General | Todo lo demás. |

Si alguien te ayudó, dilo en la respuesta: reconocer aportes es parte de nuestros acuerdos.

Los avisos oficiales del curso (horarios, cambios, asistencia) siguen llegando por el canal oficial del grupo; Discussions es para aprender juntos.

## Nuestros acuerdos

Los construimos en el primer encuentro. Versión de partida:

1. Nos tratamos con respeto y comentamos el trabajo sin descalificar a su autor.
2. Participamos por distintos medios y pedimos ayuda con una pregunta o una evidencia concreta.
3. Cuidamos el tiempo común y avisamos de dificultades de acceso.
4. Usamos los errores para formular hipótesis, probar y aprender.
5. Protegemos datos y credenciales; comprobamos las sugerencias de IA antes de utilizarlas.
6. Escuchamos, respetamos turnos y reconocemos los aportes de otros.
7. Identificamos fuentes y versiones y distinguimos resultados ejecutados, respuestas preparadas y conclusiones pendientes.

## Antes de subir algo

- **Datos ficticios siempre.** Nada de nombres, documentos o teléfonos de personas reales.
- **Nunca subas contraseñas ni claves.** Todo lo que publicas en GitHub Pages lo puede ver cualquiera.
- Este repositorio y los suyos son **públicos**. Puedes usar un nombre de usuario que no sea tu nombre real.
- **IA permitida**, siempre que puedas explicar y comprobar lo que entregas.
