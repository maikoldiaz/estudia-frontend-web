Con y sin preventDefaultMaterial del encuentro

¿Quién manda cuando envías un formulario?

Los dos formularios tienen el mismo listener de submit, que anota el nombre. Solo cambia una línea. Antes de pulsar «Reservar» en cada uno, predice qué verás en «Anotados».

Sin preventDefault

formulario.addEventListener("submit", (evento) => {
  anotados.push(nombre);
  pintar();
});

Con preventDefault

formulario.addEventListener("submit", (evento) => {
  evento.preventDefault();
  anotados.push(nombre);
  pintar();
});

Después de probar los dos

Sin preventDefault, el navegador hace lo que hace siempre con un formulario: lo envía a la dirección de la página (mira el ?nombre=Laura) y la vuelve a cargar. Lo que JavaScript anotó se pierde y el contador de cargas sube.

Con preventDefault, le dices al navegador «no hagas lo de siempre; de esto me encargo yo». La página no se recarga y lo anotado se queda.

Úsalo cuando tu JavaScript se encarga del formulario. Si no hay JavaScript que se encargue, el navegador lo envía como siempre.
