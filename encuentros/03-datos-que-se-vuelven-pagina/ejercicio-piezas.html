Cuatro piezas del JavaScript de hoyMaterial del encuentro

Predice y luego ejecuta

Antes de pulsar cada botón, di qué crees que va a salir.

1 · let o const

const sala = "Sala 1";
sala = "Sala 2";
let precios = [2500, 6000, 3000];
precios = precios.filter((p) => p < 5000);
precios;

const no deja reasignar; let sí.

2 · Función flecha

const conIva = (precio) => precio * 1.19;
conIva(4000);

Una función guardada en una variable: recibe precio y devuelve el resultado.

3 · Desestructurar

const producto = { nombre: "Pandebono", precio: 3000, categoria: "Panadería" };
const { nombre, precio } = producto;
nombre;

Saca del objeto solo lo que vas a usar. Así empieza crearTarjeta.

4 · Plantilla

const precio = 3000;
`Desde $${precio}`;

Comillas invertidas (`) y huecos ${ } donde va un dato.

Ahora en la carta

Abre la carta, pulsa F12 → Console y predice antes de cada Enter:

lista = 5;
productos.push({ nombre: "Prueba", descripcion: "Un producto nuevo", precio: 1000 });
pintar(productos);

En la carta, lista es const y productos es una lista: ¿qué cambia entre reemplazar y agregar?
