Cuando un selector dice nullMaterial del encuentro

La misma carta, una palabra de diferencia

Las dos páginas usan el mismo cafe-datos.js. Solo cambia la línea del script en el <head>.

Sin defer

<script src="cafe-datos.js"></script>

Ábrela sola, pulsa F12 → Console y lee el error: null quiere decir «no encontré nada».

Con defer

<script src="cafe-datos.js" defer></script>

defer: el script espera a que el HTML termine de cargar. Cuando busca #lista-productos, ya existe.

Si en tu página dice null, revisa en este orden

  1. ¿El nombre coincide? #lista en el JavaScript y id="lista" en el HTML.
  2. ¿Ya existía? La línea del script tiene defer.
